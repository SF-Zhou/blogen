# Configuration reference

`blogen` reads a single TOML file, `blogen.toml` by default (searched in the
current directory and its parents, or passed with `--config`). All relative paths
are resolved against the directory that contains the configuration file.

Unknown keys are rejected with an error, so typos never silently change
behaviour.

## `[site]` – required

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | string | **required** | Site name; used in `<title>`, the index page and RSS. |
| `url` | string | **required** | Canonical site URL, must start with `http://` or `https://` and must not end with `/`. Used by RSS and the profile README. |
| `description` | string | `name` | Short description used as the RSS channel description. |
| `language` | string | `en` | BCP 47 language tag, e.g. `zh-CN`; used by RSS and `<html lang>` (theme decision). |
| `default_author` | string | `web_master` or `name` | Author for articles without an author in their file name. |
| `web_master` | string | `name` | Name used in the footer copyright. |
| `google_analytics_id` | string | `""` | Google Analytics measurement id; the snippet is omitted when empty. |
| `base_path` | string | `/` | URL path prefix for sites served under a sub-path, e.g. `/blog/`. Affects `assets_url` and `images_url`. |

## `[build]`

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `posts` | path | `posts` | Markdown content directory. |
| `output` | path | `public` | Generated site directory. Must not contain `..` and must differ from `posts`. |
| `article_format` | string | `md` | Markdown file extension, without the dot. |
| `images` | string | `images` | Image directory inside `posts`, copied to `<output>/<images>`. |
| `download_remote_images` | bool | `true` | Download `http(s)` images referenced from articles into `posts/<images>` and rewrite the URLs. Source markdown is never modified. |
| `clean` | bool | `true` | Remove files generated by the previous build that are no longer produced (tracked in `<output>/.blogen-manifest.json`). |
| `parallel` | integer | `0` | Worker threads; `0` uses the number of logical CPUs. |

## `[theme]`

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | string | `default` | Bundled theme name (`blogen theme list`). |
| `path` | path | unset | External theme directory. When set, `name` is ignored. |
| `assets` | string | `dist` | Output sub-directory for theme assets, e.g. `dist` → `<output>/dist`. Must be a relative name. |

## `[markdown]`

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `toc` | bool | `true` | Replace a line containing only `[TOC]` with a table of contents. |
| `math` | bool | `true` | Render `$...$` and `$$...$$` with KaTeX. |
| `highlight` | bool | `true` | Highlight fenced code blocks with Prism (`language-<lang>` classes). |
| `mermaid` | string | `static` | `static`: render each diagram to inline SVG (light + dark) at build time with the pure-Rust renderer; `none`: leave fenced blocks as ordinary code. |

## `[profile]` – optional

When present, a `README.md` is generated from the theme's `profile.md`
template. Requires a theme that declares `[templates].profile`.

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `path` | path | `profile` | Directory that receives `README.md`. |
| `limit` | integer | `5` | Number of recent articles listed. Must be > 0. |

## `[comments.giscus]` – optional

Enables the giscus comment widget on visible article pages.

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `repo` | string | **required** | GitHub repository in `owner/repo` form. |
| `repo_id` | string | **required** | GraphQL repository id (`R_...`/`MDEw...`). |
| `category` | string | unset | Discussion category name. |
| `category_id` | string | unset | Discussion category id. |
| `mapping` | string | `title` | giscus mapping (`title`, `pathname`, `url`, ...). |
| `reactions_enabled` | string | `0` | giscus `data-reactions-enabled`. |
| `emit_metadata` | string | `0` | giscus `data-emit-metadata`. |
| `input_position` | string | `bottom` | giscus `data-input-position`. |
| `theme` | string | `preferred_color_scheme` | giscus `data-theme`. |
| `lang` | string | `en` | giscus `data-lang`. |
| `lazy_loading` | bool | `true` | Exposed to the template for lazy loading decisions. |

## `[rss]`

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `enabled` | bool | `true` | Generate the RSS feed. |
| `file` | string | `rss.xml` | Feed file name inside the output directory. |
| `limit` | integer | `20` | Maximum number of items. Must be > 0. |

The feed contains visible articles only, newest first. Articles without a date
use the build timestamp as `pubDate`.

## `[serve]`

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `host` | string | `127.0.0.1` | Interface to bind for `blogen serve`. |
| `port` | integer | `9000` | TCP port. |

## Complete example

```toml
[site]
name = "SF-Zhou's Blog"
url = "https://sf-zhou.github.io"
description = "SF-Zhou's Blog"
language = "zh-CN"
default_author = "SF-Zhou"
web_master = "SF-Zhou"
google_analytics_id = "G-GQ26H3JQ3G"

[build]
posts = "posts"
output = "public"
article_format = "md"
images = "images"
download_remote_images = true
clean = true
parallel = 0

[theme]
name = "default"
assets = "dist"

[markdown]
toc = true
math = true
highlight = true
mermaid = "static"

[profile]
path = "profile"
limit = 5

[comments.giscus]
repo = "SF-Zhou/sf-zhou.github.io"
repo_id = "MDEwOlJlcG9zaXRvcnk4MDc5ODgwNg=="
category = "Announcements"
category_id = "DIC_kwDOBNDkVs4CA6GQ"
mapping = "title"
theme = "preferred_color_scheme"
lang = "en"

[rss]
enabled = true
file = "rss.xml"
limit = 20

[serve]
host = "127.0.0.1"
port = 9000
```
